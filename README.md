# 🌾 AGROVISION : Smart Detection for Precision Farming

### 🚀 Overview
**AGROVISION** is an AI-driven precision farming project that automates the detection of crops and weeds using **Deep Learning** and **Computer Vision**.  
The system utilizes the **YOLOv3** object detection algorithm to identify and classify weeds in agricultural images, enabling targeted weeding and reduced herbicide use.  
It provides an interactive **Streamlit** web interface for users to upload field images and visualize real-time detection results.

---

## 📌 Features
- 🌱 Detects **crops** and **weeds** from agricultural field images.  
- ⚡ Real-time object detection using **YOLOv3**.  
- 🧠 Built with **Deep Learning (PyTorch)** and **OpenCV**.  
- 🌐 Interactive web app powered by **Streamlit**.  
- 🖼️ Displays bounding boxes with labels and confidence scores.  
- ♻️ Helps achieve sustainable, eco-friendly **precision farming**.

---

## 🧩 System Architecture
The system follows a three-layer architecture:
1. **Data Layer:** Handles image input and preprocessing.  
2. **Processing Layer:** Performs detection using the YOLOv3 model.  
3. **Presentation Layer:** Displays annotated results via Streamlit.
